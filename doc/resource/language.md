Asmc Macro Assembler Reference

## LANGUAGE

Defines the language for all resources to the end of the file.

syntax:

```
LANGUAGE language, sublanguage
```
#### Note

The default _codepage_ for converting "strings" to Unicode is CP\_UTF8. See [Option _codepage_](../directive/option-codepage.md) for more information.

#### Parameters

_language_

Language identifier.

_sublanguage_

Sublanguage identifier.
